# 瞬息 · 番外小剧场

本仓库基于 [小虞 / Yulia0128 的 MomentTheatre](https://github.com/Yulia0128/MomentTheatre)，保留原作者代码与提交历史，用于 TauriTavern 适配。1.0.14 修复手机顶栏与收起按钮被系统状态栏遮挡的问题；1.0.15 增加 SillyTavern 1.14.0 兼容适配。

Moment Theatre — 原生 SillyTavern 扩展，当前版本 **1.0.15**，适用于 **SillyTavern 1.14.0 及以上**。不依赖酒馆助手。

在独立窗口中生成、阅读和整理番外，保存于独立资料库，不向正文聊天插入消息。

## 功能

- 正文、小手机、HTML 三种生成模式。正文和小手机可续写，并输入本次续写要求；同一番外支持混合正文／手机章节。HTML 保留完整代码，不续写。
- 使用当前角色、当前用户面具或自填人设；选择一个预设及其提示词条目，选择多个世界书及其条目，可选读取最近正文上下文。打开角色时自动勾选其绑定的主／附加世界书；手动调整按角色记住，切换时恢复。
- 保存弹窗的分类下拉右下角可以新建分类，创建后自动勾选；分类与分类页面共用，名称不能为空或重复。
- 预设正则下方新增角色正则多选与详情，读取当前角色内的规则，本地选择／修改按角色隔离；仅用于正文阅读，编辑保留原文。
- 预设下方可多选其附带正则，点右侧箭头查看或修改名称、表达式与替换式。仅作用于正文显示，可呈现 HTML／CSS 文首美化或过滤草稿；不改酒馆源规则。章节保存当时的规则快照。
- 正文正则支持独立脚本卡片：可解析模板数据并生成 DOM，样式只作用卡片，自动适应高度；不提供酒馆助手／父窗口接口、外部脚本或 API 请求。原文仍可编辑。
- 关闭流式后等待完整生成再展示；正文加宽，半透明细滚动条位于阅读框内。
- 正文默认隐藏 think、thinking、cot 标签块（不区分大小写）及 HTML 注释，编辑仍能看到完整原文。正文规则不用于小手机或 HTML 模式。
- 跟随主 API 时与正文轮流生成；自配置独立 OpenAI 兼容 API 时可同时请求。支持流式开关和最大回复 token。
- 正文按字数、小手机按消息条数计算；不足时继续自动补写，失败保留内容并可继续补足；无进展或达到单次请求保护次数时暂停，不标记完成。长篇续写每十节形成滚动摘要。
- 多分类、标签、搜索、编辑、复制、备份恢复、按分类导出阅读文件。未保存作品只作草稿恢复，不出现在分类或分类导出中。
- 正文由 AI 按内容拟题，小手机不生成标题；预设和世界书条目全选后再次点击会清空全部条目。
- 小手机采用独立 <小手机> 框架和短格式，转账只写发送人、时间、数字金额、备注，兼容旧 JSON 与预设头尾。全部主题显示通话回应、撤回提示与原文。
- 内置 21 个表情，设置每排 10 个缩略图，图库位于 API 与数据之间；单击弹出横向编辑／删除菜单，删除再次确认，添加入口固定。新增与修改通过弹窗保存，新增追加在末尾。已删除默认表情不会自动恢复。
- 小手机编辑保留完整回复和头尾文本，阅读时提取消息，不再显示额外原始回复栏；自制阅读主题沿用相同变量和组件。生成完成不清空番外指令或续写要求。
- HTML 作品在隔离容器里运行；支持模型生成的 CSS、JavaScript、声音和交互。
- 可拖动莫比乌斯环，生成时收起仍继续，日夜界面，实际错误记录。

## 手动跨设备同步

在「设置 → 数据」操作，无需安装服务端组件或修改 PM2／Docker／命令行启动方式。电脑、手机需连接同一个酒馆服务器并登录同一个酒馆账号；Docker 的酒馆数据目录仍须按原部署方式持久挂载。

1. 有资料的设备点击「上传到服务器」：先读取服务器现有资料并合并，再上传。
2. 另一设备点击「从服务器下载」：与本机内容合并，不把本机资料上传。
3. 换设备前上传，换设备后下载；请逐台操作，避免同时上传。打开窗口、刷新、联网不会自动同步。

同篇两端修改会保留「同步副本」，可从「查看保留的副本」打开；未保存草稿仍不进入分类。某台设备缺少作品不视为删除，因此另一端保留的内容可能重新出现。同名表情冲突保留两份；主题与分类冲突保留副本。普通设置同时修改以当前设备为准，未改动设置跟随另一端；API 密钥、悬浮入口位置、当前角色／面具选择、未提交编辑框和错误记录留在本机。请先保存章节编辑再同步。

同步提交前保留本机资料快照，可以「下载同步前备份」，需要时再用「恢复备份」恢复。备份与合并结果同一事务提交，保存失败不替换当前资料。服务器每次上传保留独立快照，校验通过后更新索引；不自动清理历史文件，长期使用会占用服务器磁盘。

**请养成定期备份的习惯，重要修改前先备份全部资料。** 原生文件接口没有跨设备写入锁，上传前后核验能发现部分竞争，但不能保证同时上传时索引永远不被后写覆盖；双方快照与本机资料仍保留。发现冲突或失败后，逐台重新同步。它不能替代独立备份，浏览器或服务器自身损坏仍需从备份恢复。

## 安装与更新

1. 复制**本 GitHub 仓库**的 HTTPS 地址。
2. 酒馆 → 扩展 → 安装扩展，粘贴仓库地址，安装后刷新。
3. 点击莫比乌斯环打开瞬息。「扩展 → 瞬息 · 番外小剧场」中可开启／关闭悬浮入口，折叠箭头与外观跟随酒馆主题。
4. 后续在酒馆「扩展管理」中更新，再刷新；无需卸载重装。设置里的「检查更新」只检查版本。

安装地址是仓库地址，不是主题 JSON、ZIP 下载地址或单文件 HTML。服务器需安装 Git，且能访问 GitHub。

发布包的 `manifest.json`、`index.js`、`style.css`、`src/` 必须直接位于仓库根目录，不要多套一层文件夹。发布者步骤见 [GitHub 发布说明](GITHUB-PUBLISH.md)。

ZIP 用于手动部署或上传仓库前解压，不能作为酒馆普通文件导入。手动解压安装没有 Git 信息，不能使用仓库原位更新；需要更新便利性时从仓库安装。

## 使用说明

- 主 API 当前支持酒馆的 Chat Completion 连接；独立 API 填 OpenAI 兼容服务的地址及密钥，点击「拉取模型」后从下拉菜单选择。服务商需提供 /models 接口。最大回复 token 支持 128–200000，实际输出受模型限制。
- 新用户默认正文 5000 字、消息 50 条、最大回复 60000 token、开启流式；更新保留已有参数。正则支持范围与脚本卡片的隔离边界见接口说明。
- 密钥保存在当前浏览器、当前账号命名空间中，不进入作品或备份。使用真实 API 可能产生服务商费用。
- 输入、设置、续写要求及编辑草稿即时写入恢复记录，并自动保存资料库；同一浏览器、同一酒馆地址和账号下，收起窗口、刷新、更新与重启酒馆不会主动清空。清除浏览器数据前仍需导出备份；换设备可使用手动同步。
- 正文统一 14px，标题 26px；字体、颜色和主题装饰不变。
- 数据按当前浏览器、酒馆站点和账号隔离，更新代码不会清空作品；同一服务器／账号可手动跨设备同步，换站点前使用备份。HTML 界面预览的数据与酒馆正式数据分开。
- 部分内置主题通过外链加载图片与字体，断网或原站不可达时会使用后备字体／底色。正式包不携带大型字体文件。图片和字体按需缓存到本浏览器（最多约 64 MB，7 天有效），服务不允许跨域读取时保留原链接加载；切换页签保留阅读容器及滚动状态。
- 独立 HTML 预览使用模拟人物和示例生成，不访问真实模型；预览文件供检查界面，不能安装为扩展。为保持界面整洁，不在插件窗口显示演示提示条或模拟错误。
- 旧版开发主题从菜单退役；旧作品保存的样式仍可阅读和导出。用户自行导入的其他独立主题继续保留。
